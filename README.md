## 功能

- 挖图统计试用版：普通图／高级图独立草稿，内置五宝、兽诀、内丹、装备、书铁和花豆等快捷项，支持具体名称、自定义快捷项与记忆单价。
- 挖图结果区分直接挖出、后续战斗、线索宝箱和其他附加；放妖、幼儿园、瘴气等事件只记次数，不自动计价。
- 挖图历史可按日期／类型／地图筛选、修改与删除，支持地图统计、单图／每小时净收益以及 JSON 备份恢复。
- 挖图未售物品只计参考估值；结算后的已售／已到账收入和本轮成本合并五开总账，历史修改按原编号更新，不重复累计。同笔挖图现金如果已算进角色起止金币差额，不要再次录入；图费与点卡也请勿在其他页面重复登记。

### 挖图统计试用

简洁版录入页面顶部只显示“单价（万）”“数量（张）”两个输入框，输入时即时显示总价（单价 × 数量）。日期、角色、地图、其他费用和备注收在默认折叠的更多信息中，原有草稿和历史不清空。额外费用不混入上方乘积，结算仍按原始完整费用计算。

左右布局版沿用这一简洁顶部，下方左侧为产出快捷物品，右侧为本轮明细与结算；左右面板独立滚动，历史与备份仍保持原有数据格式。

1. 点击顶部“挖图统计”，选择普通图或高级图，填写已挖张数、每张图成本、额外成本和耗时。按地图统计时，建议每个地图单独结算；混合地图可填写“未分类”。
2. 点击产出快捷项添加物品，再填写自己的服务器参考价；也可手工添加具体技能兽诀、内丹或书铁。价格初始为零，不假设物价。
3. 仅真正卖出或收到现金的记录勾选“已售／已到账”。梦幻币数量固定为一，单价填写实际收到的万梦幻币。
4. 结算后可从历史“修改／登记卖出”更新原记录。物品估值不等于现金收入，本轮未回收成本可能显示负的已到账收支。
5. “备份与恢复”只处理挖图模块，不覆盖手工记账、跑环、场景或攻略。此版为手工录入工具，不读取游戏内存、不自动挖图。

挖图额外检查：`node check-treasure.cjs`、`node check-treasure-accounting.cjs`。隔离界面测试：`node node_modules/electron/cli.js check-treasure-ui.cjs`；生成的截图含测试示例数据，不代表游戏收益。

### 其他现有功能

- 实用工具箱：五个角色独立培养预算，按填写的需求汇总经验、费用与帮贡；预算不记入实际账目。
- 可编辑攻略库：帮派迷宫、神器与副本分类，内置三篇简要资料，支持搜索、新增、修改、复制、删除与 JSON 备份恢复。来源和版本随条目保存。
- 定时提醒与定时关闭游戏：选择实际客户端 EXE，勾选对应窗口并确认定时；到时请求正常关闭，遇到游戏确认框需手动处理。进程路径和启动时间变化时跳过；退出记账本取消定时。

- 场景记账：按次记录召唤兽和物品收益，采用左边图片选物品、右边录入与明细的紧凑双栏，结算后合并五开总账。账号数量、计时与点卡成本在五开主页面统一管理，场景不再重复登记。
- 场景资料：从金算盘源码导入 260 条召唤兽记录，统一为 70 个场景；支持场景联动推荐召唤兽、自定义项目、历史修改和 JSON 备份恢复。
- 场景草稿和历史保存在本机 `mh_scene_project_v1`；召唤兽与物品按出售金额或估值填写。旧版已有金币或成本明细继续兼容，不会自动删除或重新迁移到主账。
- 五开记账：角色金币、物品收益、点卡成本、比例设置、收入统计。
- 跑环记账：宠环、人环、逐环支出、自定义价格、收益登记及历史结算。
- 固定领取费 10 万；书、铁、灵饰书、灵饰铁、修炼果与战魄收益登记。
- 跑环结算合并五开总账：计入奖励并扣除跑环成本，重复读取不重复计账。
- 价格清单导入导出、主题切换。
- 联系与支持：作者微信、微信与支付宝自愿打赏、小程序链接复制。
- 底部“打开小宝贝金算盘”：点击显示微信小程序码，支持扫码和复制小程序口令。

### 场景双栏与书铁图片版（2026-10-27）

- 场景左栏保留 60／70／80 武器、防具、炼妖石，以及当前场景对应的召唤兽；选择只预填表单，提交后才增加收支。
- 常用地图改为固定下拉框，仅提供无名鬼城、青丘、银华境、须弥东界、鬼市、五行山六项；不会受输入文字过滤而只剩一个选项。新记录默认无名鬼城。旧“银华镜”“5行山”兼容对应宠物；含账目的旧草稿和历史保留原始地图名。资料生成器只规范楼层数字，不再把“五行山”错误转换成“5行山”。
- 场景新录入类型只保留“召唤兽”和“物品”，移除“金币”“成本”入口。已有金币和成本明细继续保留并按原规则计算，编辑旧明细时类型只读，不会将旧成本误计成收入。
- 右栏集中显示类型、名称、数量、单价、明细与结算。左右独立滚动，历史与备份各自放在单独页面。
- 删除原“本次场景记账”信息面板，不再展示日期、耗时／备注输入、大统计卡、宠物资质资料或冗长说明；新记录日期默认当天，场景选择移入左栏。历史页移除按场景汇总和每小时收益。已有记录中的日期、耗时、备注、价格及账目数据仍保留。
- 制造指南书、百炼精铁替换为已核实的电脑版网页图片，所有引用共享图标的页面一起生效；来源与版权边界见 `THIRD_PARTY_NOTICES.md` 和 `dist/icons/treasure/manifest.json`。六个常用场景的 55 种召唤兽使用本地参考图片，左栏、右侧明细和历史保持一致；原图及来源在 `dist/icons/scene-pets/manifest.json`。司辰侍者（未来）按公开图鉴明确的未来普通槽配图，非带名游戏面板的独立验证。

### 场景召唤兽技能数（2026-10-27）

- 本次增加的是“有几个技能”，不是召唤兽等级或角色携带等级。场景录入选择召唤兽后可填技能数；普通物品不显示该字段。
- 明细与历史显示技能数；“按技能数统计”默认折叠，展开后按“召唤兽名称＋技能数”统计只数和金额，历史统计跟随场景筛选。仍保持左右栏与底部结算按钮。
- 3 技能、4 技能、0 技能及“未填写”是独立价格档。新档首次录入后会出现在共用价格表；没有参考价的技能档不会借用其他档价格。技能数本身不参与乘价，金额仍为数量乘单价。
- 旧记录不补写技能数，不会推测成 0。编辑已有明细时改变技能数也不会静默改动实际单价。导出、恢复、历史修改和总账标签保留技能数，图片仍使用对应召唤兽。
- 技能数接受留空或 0～99 的整数，这是记账表单范围，不表示游戏技能上限。新行字段为可选数值 `skillCount`，旧无字段记录兼容。

### 共用价格与挖图分类统计（2026-10-27）

- 顶部“共用价格”打开统一参考价表。五开主页面、跑环、场景、挖图读取同一套价格；保存即生效，无需逐页重复填写。金额单位为万，支持四位小数；明确填 0 有效。
- 同类环装名称归一：60级武器与60武器相同，60装备与60防具相同（70/80同理）；玫瑰与红玫瑰相同。不同等级的书铁、不同类型的制造书、具体兽诀技能和内丹分别计价；宠物与普通物品不混淆。泛称如“低级魔兽要诀”“炼妖石”不强行套用统一价格。
- 挖图固定价物品、自定义价物品、现金分区展示，各自显示数量、估值和已到账。固定价默认含五宝、60/70/80环装、花豆和书铁（制造书、百炼精铁、灵饰书铁）。铁按等级、书按等级和具体种类分别设置；固定价仍可修改，不代表全服统一价格。无具体种类的制造书不强行共用一口价。
- 新记录保留计价分类快照；改参考价格不重算已录入明细和结算历史。已有明确记录为自定义价的历史书铁保留原分组，旧记录没有分类字段时按现行分类显示，金额不变。旧共享价表中的书铁自定义分类仍可读取，在界面规范显示为固定价，不自动改写存储中的价格数值。
- 价格变化只影响以后新选取/添加的物品。正在输入的表单、已有明细价格不自动替换，实际成交价仍可逐条修改。挖图未到账物品仍不计入总账。
- 共享价格独立保存在 `mh_shared_item_prices_v1`。首次使用从主页面非零固定价、场景、挖图、跑环依序补齐缺项；跑环内部“两”正确转换为“万”。旧草稿、历史和总账不会因为参考价迁移而重写。
- 正式安装包构建：`npm run dist:win`；隔离回归：`node node_modules/electron/cli.js check-scene-split-ui.cjs`、`node node_modules/electron/cli.js check-item-images-ui.cjs`。测试截图为合成数据，不代表实际游戏收益。

## v1.1.0 自动更新版

首次使用请下载 Releases 中的 `xiaobaobei-ledger-Setup-1.1.0.exe`，安装一次。此后启动 15 秒后后台检查新版，每两小时重试；自动下载，正常关闭软件后安装，下次打开生效。不会在记账途中强制重启。帮助菜单支持手动检查。GitHub 连接失败时继续使用当前版本。旧 ZIP 无法自动升级，需要先安装此版本。

安装版沿用 `%APPDATA%/mh-five-accounting` 中的本地账目、价格和设置；卸载默认不删除这些数据。升级不要同时打开 ZIP 版与安装版。

自动更新安装包使用每用户安装，无需管理员权限。下载校验由 electron-updater 按发布清单执行。

## 代码状态与目录

当前仓库公开的是实际使用的 Electron 入口、可编辑的扩展模块，以及五开主界面的编译产物。**原始 Vue 单文件组件不在当前材料中，因此这是现有可运行版本的公开，不是完整 Vue 开发工程。**

- `electron/`：窗口、菜单及本地文件/剪贴板接口。
- `dist/assets/ring-project.js`：跑环录入、价格、奖励与结算。
- `dist/assets/ring-accounting.js`：跑环与五开总账合并。
- `dist/assets/support-project.js`：联系与支持页面。
- `dist/assets/price-list.js`、`role-gold.js` 等：价格、金币与界面扩展。
- `dist/assets/index-*.js`、`index-*.css`：五开主界面及其 Vue 等第三方依赖的编译产物。
- `docs/`：功能说明及界面预览。

项目包名仍保留 `mh-five-accounting`，以沿用现有桌面版本的数据目录。显示名称为“小宝贝记账本”。仓库不包含用户实际账目、浏览器配置、登录凭据和旧版程序备份。
